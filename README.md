## Технологии

- Платформа: WPF (Windows Presentation Foundation), .NET 8, язык C#;
- СУБД: Microsoft SQL Server (подключение через ADO.NET, System.Data.SqlClient);
- Структура БД: третья нормальная форма (3НФ), ссылочная целостность (PK/FK);
- Данные импортированы из файлов заказчика (import: Tovar.xlsx, user_import.xlsx,
  Заказ_import.xlsx, Пункты выдачи_import.xlsx).

## Развёртывание

1. Создайте базу данных: выполните скрипт `db/schema.sql` в SQL Server Management
   Studio (SSMS). Скрипт создаёт БД, таблицы, ключи, связи и загружает данные импорта.
2. При необходимости измените строку подключения `ConnectionString` в начале файла
   `App.xaml.cs` (по умолчанию `Data Source=(local)`, локальный экземпляр SQL Server,
   Windows-аутентификация).
3. Запуск готового приложения: исполняемый файл `publish\<Имя>.exe`. Папка
   `publish` самодостаточна — библиотека ADO.NET (`System.Data.SqlClient.dll`
   и `sni.dll`) лежит рядом, интернет и NuGet не требуются, нужен только
   установленный .NET 8 Desktop Runtime (или новее).
4. Открытие в Visual Studio: решение `.sln` собирается офлайн — проект не
   зависит от NuGet-пакетов, SqlClient подключён локальной ссылкой
   (`lib\System.Data.SqlClient.dll`).
5. Резервная копия БД: выполните `db/backup.sql` (формирует файл
   `user<Номер рабочего места>.bak` и выполняет пробное восстановление).

## Функционал

- Авторизация по данным из БД, вход как гость;
- Список товаров из БД: фото (или заглушка picture.png), перечёркнутая красным
  старая цена + итоговая чёрная, подсветка строк по скидке и остаткам на складе;
- Поиск, сортировка и фильтрация в реальном времени (менеджер/администратор):
  - Вело: фильтр по диапазонам скидки (0–11,99 % / 12–18,99 % / 19 % и более),
    сортировка по цене, складу, скидке; подсветка скидки > 15 % (#483D8B),
    отсутствие на складе — серый;
  - Игрушки: фильтр по поставщику, сортировка по цене и складу;
    подсветка скидки > 17 % (#FFDEAD), отсутствие на складе — голубой;
- Администратор: добавление/редактирование/удаление товаров (фото до 300x200,
  удаление запрещено для товаров из заказов, одно окно редактирования),
  полное управление заказами и управление пользователями (добавление,
  редактирование, блокировка/разблокировка); менеджер — поиск, сортировка, фильтрация
  и просмотр всех заказов; клиент — просмотр своих заказов и оформление
  нового (статус «Новый» фиксирован); гость — только каталог. Оформление
  заказа списывает товар со склада, удаление заказа возвращает на склад.

## Особенности реализации

- Простая структура: только XAML-разметка и code-behind, вся логика — в обработчиках
  окон; общие настройки (строка подключения, цвета, работа с фото) — в `App.xaml.cs`;
- Списки загружаются из БД в DataTable (SqlDataAdapter), поиск/сортировка/фильтрация
  выполняются в памяти в реальном времени;
- Идентификаторы — CamelCase, ключевые места пояснены комментариями;
- Обработка исключений: глобальный обработчик `DispatcherUnhandledException` +
  информативные MessageBox с пиктограммами (ошибка/предупреждение/информация);
- После каждой операции списки товаров и заказов обновляются из базы данных.
